# LG 트윈스 드래프트 아카이브

2011–2027년 LG 트윈스 신인 지명과 신고·육성 입단 선수 정보를 살펴보는 개인 팬 프로젝트입니다.

## 사용

`index.html`을 브라우저에서 열면 됩니다. CSS, JavaScript, 선수 데이터와 사진이 HTML에 포함되어 있습니다.
선수를 선택하면 프로필과 경력, 기록 및 출처를 확인할 수 있습니다.

## 자료 기준

2026년 9월 24–25일 확인 자료를 바탕으로 한 정적 스냅샷입니다. 실시간 갱신되지 않으며 미확인 정보가 포함되어 있습니다.
공식 구단 사이트가 아닙니다. 선수 사진과 외부 자료의 권리는 각 원권리자에게 있으며, 출처는 페이지에 표시합니다.

## 배포

GitHub 저장소의 Settings → Pages → Deploy from a branch에서 main / (root)를 선택합니다.
